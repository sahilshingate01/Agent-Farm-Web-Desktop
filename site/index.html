Beyond account routing

One control plane for the whole crew.

Agent Farm combines provider access, knowledge, tooling and live capacity without pretending that separate agents or providers are the same system.

Universal gateway

Point any OpenAI- or Anthropic-compatible app at one endpoint. The gateway presents chat, responses and messages APIs, maps model names, preserves streaming and tools, and applies quota-aware routing.

02

Run anywhere

Any machine can become a silo.

Install agensis-cli wherever the work and model access live. It makes an outbound workspace connection, so a personal workstation, server or managed sandbox can join the same crew without copying its home directory.

01 / Your infrastructure

No sandbox required

Run npm install -g agensis-cli on a machine you control, choose the working folder and authenticate the coding tools there. Farm discovers it through the paired Agensis workspace.

02 / Shared inference

Local models, workspace-wide

Advertise selected loopback OpenAI-compatible models without exposing their private endpoint or key. Use them from Agensis web, desktop and the Farm crew route.

03 / Managed cloud

E2B and Daytona

Provision isolated coding silos from the same control plane. E2B workers pause after inactivity; Daytona workers auto-stop and relaunch their Agensis daemon when needed.

Provider credentials are completed inside each environment. Farm stores only its scoped Agensis pairing and runtime identifiers.
